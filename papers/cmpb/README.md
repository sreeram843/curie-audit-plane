# CMPB packaging

Elsevier `elsarticle` preprint source for *Computer Methods and Programs in
Biomedicine*. Frozen research claims match `papers/jbhi/`; this folder is the
active submission format. Do not treat the two packages as simultaneous
submissions of the same paper.

- `main.tex` / `references.bib` — sole canonical CMPB manuscript source
- `main.pdf` — compile with `pdflatex` + `bibtex` from this directory
- `highlights.txt` — 3–5 bullets, each ≤85 characters including spaces
- `cover_letter.txt` / `cover_letter.tex` — Editorial Manager cover letter
- `gagraphic.tex` — graphical abstract
- `submission/` — upload package (`assemble_submission.sh`)
- `SUBMISSION_CHECKLIST.md` — remaining human/portal steps

Portal: https://www.editorialmanager.com/cmpb/
